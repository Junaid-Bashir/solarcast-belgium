# API reference

Signatures and docstrings are generated from checked-out source, without importing optional ML runtimes. These docs track main; record your installed `solarcast.__version__`.

- [benchmark()](benchmark.md): run comparisons.
- [BenchmarkConfig](config.md): dates, assumptions and model settings.
- [BenchmarkResult](result.md): rankings, predictions and failures.
- [available_models()](discovery.md): discover dependency status.
- [ModelInfo](model-info.md): immutable discovery records.

See the [API cheat sheet](../getting-started/cheat-sheet.md), [public API guide](../public-api.md) and [advanced forecasting interface](../forecasting-interface.md).
