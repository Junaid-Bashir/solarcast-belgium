# Security reporting

SolarCast 0.1.0 is research software. No dedicated security email,
response-time commitment or supported-release policy has been established.

GitHub private vulnerability reporting is enabled. Use the repository's
[Security → Report a vulnerability](https://github.com/Junaid-Bashir/solarcast-belgium/security/advisories/new)
route for suspected vulnerabilities. Do not put credentials, sensitive data or
exploit details in public issues. If the private route is unavailable, make only
a non-sensitive request to restore private reporting through a public issue.

Reports should describe the affected version, impact and minimal reproduction,
with sensitive material redacted. Ordinary forecasting errors and methodological
questions belong in normal issues and should disclose availability/leakage concerns.
